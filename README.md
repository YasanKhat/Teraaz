# تبار

**همراهِ کاملِ درس «تاریخ ۲» — پایهٔ یازدهم، رشتهٔ ادبیات و علوم انسانی**

از خواندنِ خشک به **سفر در تاریخ**: روایت، خط زمان، نقشه، چهره‌ها، کارت مرور و آزمون شبیه‌ساز امتحان نهایی — همه در یک برنامهٔ فارسی، راست‌به‌چپ و کاملاً آفلاین.

## این برنامه چه می‌کند؟

تبار فقط یک «خلاصهٔ کتاب» نیست. برای هر یک از ۱۶ درس، یک تجربهٔ یادگیری کامل ساخته شده است:

| بخش | چه چیزی به دست می‌آوری |
|---|---|
| **درس‌نامهٔ روایی** | هر درس با یک قلاب داستانی آغاز می‌شود، سپس متن کامل آموزشی با جدول، نکته، هشدار «اشتباه رایج»، نقل‌قول و گام‌های علت‌ومعلولی می‌آید. |
| **جمع‌بندی و امتحان** | نکات کلیدی، حافظه‌یار (مُنتال‌اِم‌نیک)، نکته‌های امتحانی و بارم‌بندی هر درس بر پایهٔ جدول بارم کتاب. |
| **کارت مرور فاصله‌دار** | واژه‌نامهٔ هر درس به کارت تبدیل می‌شود و با الگوریتم جعبه‌ای (۱، ۲، ۴، ۸ روز) زمان مرور را خودش تنظیم می‌کند. |
| **آزمون** | آزمونک هر درس با پاسخ تشریحی، چهار آزمون جامع شبیه‌ساز نوبت اول و دوم با زمان‌سنج، برگهٔ پاسخ و پاسخنامه. |
| **خط زمان** | ۸۴ رویداد از جاهلیت تا پایان صفویه، قابل فیلتر و جست‌وجو، با پیوند به درس مرتبط. |
| **نقشهٔ تاریخی** | ۳۸ شهر و ۱۷ نشانه (نبرد، بنا، رویداد) روی نقشهٔ واقعی جهان اسلام و ایران، همراه با مسیرهای تجاری و لشکرکشی. |
| **چهره‌ها** | ۵۳ شخصیت تاریخی با Bio، دستاوردها، نکتهٔ امتحانی و درس‌های مرتبط. |
| **پیشرفت و نشان** | سطح، امتیاز، زنجیرهٔ مطالعهٔ روزانه، ده‌ها نشان، کارنامهٔ آزمون‌ها و برنامهٔ مطالعهٔ هفت‌روزه. |

## برای «نمرهٔ بیست» چه دارد؟

- **۱۵۴ پرسش چهارگزینه‌ای و صحیح/غلط** با پاسخ تشریحی، در سه سطح دشواری و با برچسب منبع (کتاب درسی / امتحان نهایی / تألیفی).
- آزمون‌های **نوبت اول** (درس ۱–۸) و **نوبت دوم** (کل کتاب) با همان نسبت‌های بارم‌بندی.
- درس‌نامه‌ها نکته‌های «این جمله را دقیق بنویس» را جدا کرده‌اند؛ همان جمله‌هایی که در تصحیح، نمره می‌سازند.
- «حافظه‌یار» برای فهرست‌های حفظی (سلسله‌ها، جنگ‌ها، علل، ویژگی‌ها).
- کلیدواژه‌های دو زبانه (فارسی/لاتین) برای واژه‌های تخصصی.

## تجربهٔ کاربری

- **فارسی و راست‌به‌چپ** از پایه؛ اعداد فارسی، تاریخ شمسی، فونت‌های Estedad و Vazirmatn و تیترهای نستعلیق.
- **دو پوسته**: «شب و لاجورد» (تیره) و «کاغذ و مرکب» (روشن).
- **کاملاً آفلاین**: هیچ درخواست شبکه‌ای در زمان اجرا وجود ندارد؛ نقشه و فونت‌ها محلی‌اند.
- **ذخیرهٔ خودکار** پیشرفت، یادداشت‌ها و کارت‌ها در `localStorage`، با خروجی/بازیابی JSON.
- **دسترس‌پذیری و آرامش**: احترام به `prefers-reduced-motion`، کلید خاموش‌کردن انیمیشن، مقیاس اندازۀ متن، ناوبری با کیبورد و جست‌وجوی سراسری با `Ctrl/⌘ + K`.
- **طراحی واکنش‌گرا**: نوار کناری در دسکتاپ، نوار پایین در موبایل، و چیدمان چاپ برای درس‌نامه.

## مسیرهای برنامه

```
#/                خانه و برنامهٔ امروز
#/lessons         همهٔ درس‌ها + بارم‌بندی
#/lesson/:id      درس‌نامه، جمع‌بندی، کارت‌ها، آزمون، یادداشت
#/timeline        خط زمان تعاملی
#/map             نقشهٔ تاریخی
#/figures         چهره‌ها
#/quiz            آزمون‌ها و آزمونک
#/cards           کارت‌های مرور فاصله‌دار
#/game            چالش سریع ۶۰ ثانیه‌ای
#/progress        کارنامه و نشان‌ها
#/settings        تنظیمات و پشتیبان‌گیری
```

## اجرا

```bash
npm install
npm run dev:web      # پیش‌نمایش وب روی http://localhost:5173
npm run build:web    # خروجی وب در out/web
npm run typecheck    # بررسی نوع‌ها
npm run dev          # نسخهٔ Electron
```

> برای نصب در محیط‌هایی که گواهی TLS محدود است: `ELECTRON_SKIP_BINARY_DOWNLOAD=1 npm install`.

## ساختار

```
src/renderer/src/
├─ data/            محتوای کامل درس‌ها (۱۶ فایل/بلوک)، خط زمان، چهره‌ها، نقشه، آزمون‌ها
├─ components/      طراحی مشترک: Shell، QuizRunner، Flashcards، TimelineView، MapView، ui
├─ pages/           یازده صفحهٔ برنامه
├─ store/           وضعیت ماندگار (پیشرفت، کارت‌ها، تنظیمات) با zustand
├─ lib/             مسیریابی هش، جست‌وجو، نشان‌ها، ابزارها
└─ assets/          سیستم طراحی (Tailwind 4 + CSS سفارشی)
```

## منابع محتوا

محتوای آموزشی بر پایهٔ **کتاب درسی تاریخ ۲ (پایهٔ یازدهم انسانی)** و **کتاب «ماجرای بیست» (خیلی سبز)** تدوین شده است؛ پرسش‌ها با الگوی امتحان‌های نهایی هم‌راستا شده‌اند. برنامه برای مطالعهٔ شخصی ساخته شده و جایگزین کتاب درسی نیست.
